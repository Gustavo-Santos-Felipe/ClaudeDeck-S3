# ClaudeDeck-S3
An open-source, ESP32-S3-powered mechanical macropad designed for developer productivity and Claude AI integration. Features 10 hot-swappable mechanical switches with per-key RGB backlighting, a rotary encoder, and an I2C OLED display for real-time status and shortcut navigation.
